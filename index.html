Developer: Rajesh R Mohan  |  How to Play
🌙 The Story: The village of Aethoria is under siege. Two guards have stolen the Crystal Key that seals the ancient Evil Gate. You are the hero — but you cannot move on your own. Write JavaScript code in the editor to command your hero, defeat the guards, retrieve the key, and escape through the Exit Gate before darkness falls.

🎯 Objectives (in order)

1 Defeat both Guards — move near them and call hero.attack()
2 Walk onto the Crystal Key tile and call hero.pickUp()
3 Navigate to the green Exit Gate (bottom-right) to win

🕹 How It Works

Type commands in the solution.js editor on the right. Press ▶ Run Code to execute them step-by-step with animations. Use ↺ Reset to start over at any time. Adjust the 🐢→🐇 speed slider to slow down or speed up playback.

Your code is real JavaScript — so for loops, variables, and functions all work. The hero object is your only interface to the game world.

📜 Command Reference

CommandEffect
hero.moveUp(n) Move n tiles upward (default 1)
hero.moveDown(n) Move n tiles downward (default 1)
hero.moveLeft(n) Move n tiles to the left
hero.moveRight(n) Move n tiles to the right
hero.attack() Strike the nearest enemy within 2 tiles
hero.pickUp() Collect the item on your current tile
hero.say("text") Display a speech bubble above the hero
for / while loops Standard JS loops work natively
💡 Tips
▸ Guards are defeated in 1 hit — but you must be within 2 tiles.
▸ You must be standing on the Key tile to pick it up.
▸ The Exit Gate (green glow) is at the right edge, row 8.
▸ Walls, trees, water, and houses are impassable.
▸ Use hero.say() to debug your hero's position visually.
